# User Story: Interactive Map

## Requirement
As a user, I want to view nearby locations on an interactive map, so that I can better understand their proximity and surroundings.

## Details
- Map is visible on the left side of the screen.
- Clicking on the map selects a staring point and fetches nearby locations.
- After clicking location:
  - The popup displaying location name appears.
  - Location should be selected and scrolled to view in the right panel.
- Map supports zooming and panning.
