# User Story: Hotel Booking

## Requirement
As a client, I want to be able to book a selected hotel by sending data from reservation form.

## Required Fields
- Hotel ID
- Hotel Name
- First Name
- Last Name
- Birth Date
- Email
- Start Date
    - must be in the future or today 
- End Date
    - must be in the future
    - must be after start date
- Number of Guests
    - max: 10

## Additional conditions
- There should be no possibility to book a hotel for the same user in different hotels on the same days.
